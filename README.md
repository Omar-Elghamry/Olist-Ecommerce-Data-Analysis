# Olist E-commerce Data Analysis

## Project Overview
This project analyzes the Brazilian Olist E-commerce dataset using Python to explore sales performance, customer behavior, product categories, and order information.

## Tools & Libraries
- Python
- pandas
- NumPy
- Matplotlib

## Project Workflow
1. Data Loading and Exploration
2. Data Cleaning
3. Data Merging
4. Exploratory Data Analysis
5. Sales Analysis
6. Data Visualization

## Dataset
Brazilian E-commerce Public Dataset by Olist, available on Kaggle.

## Analysis
- Total Revenue
- Total Orders
- Total Products Sold
- Average Order Value
- Top 10 Product Categories by Revenue

## How to Run
Install the required libraries:

```bash
pip install pandas numpy matplotlib
```

Run the project:

```bash
python project.py
```
